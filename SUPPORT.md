# Support

For setup and usage questions, first review the
[installation guide](docs/INSTALLATION.en.md),
[entity catalog](docs/ENTITY_CATALOG.md), and
[vehicle capability matrix](docs/VEHICLE_CAPABILITY_MATRIX.en.md).

Use GitHub Issues for reproducible bugs and well-defined portable feature proposals. Use [GitHub Discussions](https://github.com/CaneTLOTW/sv_dashboard/discussions) for setup/usage questions, early ideas, compatibility observations and dashboard sharing. Use a private GitHub security advisory for vulnerabilities or accidental private-data exposure.

See the [community guide](docs/COMMUNITY.en.md) for project scope and privacy rules. Do not post VINs, credentials, exact locations, raw exports or Home Assistant `.storage` files in public threads.
